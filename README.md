# STREAK — Full-stack E-commerce Portfolio v4

Marketplace-style e-commerce portfolio for TorStaq.

### Run
npm install
npm start
http://localhost:3000

### Added in v4
- 30 products across Men, Women, Footwear, Electronics, Accessories, Home & Living, Beauty and Sports
- Category-specific product sections on homepage
- Large product catalog with search/category filtering
- Detailed product pages with product details, features, sizes, colors, stock, ratings and review counts
- Add to Bag + Buy Now
- Cart quantity controls
- Checkout Step 1: items, product prices and delivery address
- Checkout Step 2: UPI, Card and COD payment options
- UPI demo popup clearly stating no real payment is charged
- Order confirmation
- Register/login with account name shown in the header after login
- Wishlist
- Persistent cart/wishlist/user state in browser localStorage
- Existing Express APIs and JSON order storage retained

Review counts/ratings are demo storefront data, not real customer reviews.
Payment is a demo UI; no real payment is processed.

Help & Support and Track Order currently show a simple demo message indicating the team is working on those features.
